# Contributing to Ohara

First off, thank you for considering contributing to **Ohara**. Every contribution, whether it's fixing a bug, improving documentation, reporting an issue, or adding a new feature, helps make the project better.

## Before You Start

Before opening an issue or submitting a pull request:

* Check if a similar issue or pull request already exists.
* Read the project documentation.
* Keep discussions respectful and constructive.

## Reporting Bugs

When reporting a bug, include:

* Expected behavior
* Actual behavior
* Steps to reproduce
* Environment information
* Screenshots or logs if applicable

## Suggesting Features

Feature requests should include:

* The problem being solved
* Proposed solution
* Possible alternatives
* Additional context

## Community Standards

- Follow the expectations in [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md).

## Code Review

Reviews should focus on:

* Correctness
* Readability
* Maintainability
* Performance
* Security

Feedback should always remain constructive and respectful.
